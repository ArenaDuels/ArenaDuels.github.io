ArenaDuels generated PNG skin textures
=====================================

The 16 skin PNGs in assets/skins/ were split from the generated 4x4 texture atlas.
They are used both for the customization picker previews and as Three.js material maps.

Skin IDs:
neon, galaxy, fire, ice, camo, digital, lava, rainbow, gold, glitch,
carbon, contour, crown, lightning, smoke, checker.

Solid is the only option that uses the selected player color. All other skins use
their own image colors. This package is based on the supplied ArenaDuels healthbar-fix
source archive, so its other game files are retained.
